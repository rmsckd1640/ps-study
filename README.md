## 시간 복잡도별로 N의 가용 범위

> 제한 시간 1초 기준

| 시간 복잡도 | 대략적인 N 범위 |
|:---:|:---:|
| $O(N!)$ | $N \le 10$ |
| $O(2^N)$ | $20 \sim 25$ |
| $O(N^3)$ | $200 \sim 300$ |
| $O(N^2)$ | $3000 \sim 5000$ |
| $O(N \log N)$ | $100만$ |
| $O(N)$ | $1000 \sim 2000만$ |
| $O(\log N)$ | $10억 이상$ |
