# PS study

문제 해결 과정과 사고 흐름을 기록하며 꾸준히 학습하는 PS 저장소

---

## 제한 시간이 1초인 문제에 각 시간 복잡도별로 허용할 수 있는 N의 가용 범위

| 시간 복잡도 | 대략적인 N 범위 |
|:---:|:---:|
| $O(N!)$ | $N \le 10$ |
| $O(2^N)$ | $20 \sim 25$ |
| $O(N^3)$ | $200 \sim 300$ |
| $O(N^2)$ | $3000 \sim 5000$ |
| $O(N \log N)$ | $100만$ |
| $O(N)$ | $1000 \sim 2000만$ |
| $O(\log N)$ | $10억 이상$ |
