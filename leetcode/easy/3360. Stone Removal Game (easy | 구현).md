## 문제 요약

숫자 n이 주어지고 Alice부터 n에서 10을 뺌.

그 다음 Bob은 1 줄어든 n에서 10 뺀 값의 9를 뺌.

반복.

만약 뺄 수 없을 경우(음수가 되는 경우) 지는 게임.

## 핵심 조건 및 제약 사항

숫자 n 범위 → 1 ~ 50

## 시행착오

10부터 하나씩 줄이며 빼는데 뺐을 때 음수가 아니라면 카운팅.

최종 카운트 값이 홀수면 Bob이 못 뺀 경우니 Alice 승리.

짝수면 반대경우로 Bob 승리

## 구현

```java
class Solution {
    public boolean canAliceWin(int n) {

        //홀수 -> Ailce 승
        //짝수 -> Bob 승
        int cnt = 0;

        int i = 10;
        while(true){
            n -= i;
            i--;

            if(n < 0) break;
            cnt++;
        }
        
        if(cnt % 2 == 1) return true;
        return false;
    }
}
```
