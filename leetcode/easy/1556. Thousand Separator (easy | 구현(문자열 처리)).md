## 문제 요약

천의 자리마다 점 찍기

## 핵심 조건 및 제약 사항

n 범위 → 0 ~ $2^{31}$ - 1

## 시행착오

주어진 값을 `StringBuilder`로 사용하여 끝에서 3번째 자리부터 3번째마다 점 insert

## 구현

```java
class Solution {
    public String thousandSeparator(int n) {
        
        StringBuilder sb = new StringBuilder(String.valueOf(n));

        for(int i=sb.length()-3; i>0; i-=3){
            sb.insert(i, ".");
        }

        return sb.toString();
    }
}
```

## 회고

여러 문제를 접하면서  `StringBuilder`가 매우 요긴하게 쓰인다는 걸 느꼈다.

`StringBuilder`에 대해 다양한 메서드와 사용법을 익히고 적용해봐야겠다.
