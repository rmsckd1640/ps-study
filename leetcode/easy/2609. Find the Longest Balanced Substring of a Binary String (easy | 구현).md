## 문제 요약

0과 1의 개수가 같은 가장 긴 연속된 길이를 구해라.

0은 모두 앞, 1은 모두 뒤에 있어야 함.

## 핵심 조건 및 제약 사항

주어지는 문자열 길이 → 1 ~ 50

## 시행착오

0이 등장하면 0카운팅하고 1카운트는 0으로

1이 등장하면 1 카운팅하고 0카운트랑 1카운트중 작은거로 갱신

## 구현

```java
class Solution {
    public int findTheLongestBalancedSubstring(String s) {
        int zeroCnt = 0;
        int oneCnt = 0;

        int answer = 0;
        for(int i=0; i<s.length(); i++){
            
            if(s.charAt(i) == '0'){
                if(oneCnt != 0){
                    zeroCnt = 0;
                    oneCnt = 0;
                }
                zeroCnt++;
            }

            else{
                oneCnt++;
                answer = Math.max(2 * Math.min(zeroCnt, oneCnt), answer);
            }
        }

        return answer;
    }
}
```
