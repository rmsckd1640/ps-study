## 문제 요약

두 배열의 가장 작은 숫자를 모두 포함하는 제일 작은 수를 구하라.

## 핵심 조건 및 제약 사항

배열 크기 → 1 ~ 9

배열 원소 크기 → 1 ~ 9

각 배열에서 원소는 유일함

## 시행착오

해시테이블 써서 2개인거 무조건 답

1개인거만 있으면 제일 작은 것 두개를 제일 작게 조합하면 답 → 1개인거만 으로 하면 한 곳에서만 고를 수 있음.
→ 2개인 경우가 없으면 각 집합에서 제일 작은 수 뽑아서 계산

## 구현

```java
import java.util.*;

class Solution {
    public int minNumber(int[] nums1, int[] nums2) {
        
        HashMap<Integer, Integer> map = new HashMap<>();

        int min1 = 1_000_000_000;
        int min2 = 1_000_000_000;

        for(int i=0; i<nums1.length; i++){
            map.put(nums1[i], map.getOrDefault(nums1[i], 0) + 1);
            min1 = Math.min(min1, nums1[i]);
        }

        for(int i=0; i<nums2.length; i++){
            map.put(nums2[i], map.getOrDefault(nums2[i], 0) + 1);
            min2 = Math.min(min2, nums2[i]);
        }


        int min = 1_000_000_000;
        for(Map.Entry<Integer, Integer> entry : map.entrySet()){
            if(entry.getValue() == 2){
                min = Math.min(min, entry.getKey());
            }
        }
        if(min != 1_000_000_000) return min;

        int temp = 0;
        if(min1 > min2){
            temp = min2 * 10 + min1;
        }
        else{
            temp = min1 * 10 + min2;
        }

        return temp;
    }
}
```
