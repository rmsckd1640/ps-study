## 문제 요약

2차원 배열 각 행에서 숫자 하나씩 누적해서 더한 값이 target과 차이가 최소가 되는 값을 출력.

## 핵심 조건 및 제약 사항

행 m, 열 n → 1 ~ 70

mat[i][j] → 1 ~ 70

## 시행착오

백트래킹으로 풀어보려 했지만 경우의 수가 n^m개 나와 터질 것이 분명했다. → dp로 풀어보자.

각 행에서 선택한 값을 누적할 때 상태를 담아둘 배열이 필요함.

행 최대 크기 70, 배열 값 최대 크기 70 → 모든 행에서 가장 큰 값만 골라도 4900이므로 배열 크기는 5000으로 넉넉하게 잡기.

공간을 효율적으로 쓰기 위해 1차원 boolean 배열을 사용해 직전 행의 합만 다음 행으로 전파하기로 함.

이때 배열 하나만 두고 바로 갱신하면 방금 구한 합에 같은 행의 숫자가 또 더해지는 중복 문제가 발생하므로, 직전 행의 기록(dp)과 새로운 행의 기록(nextDp)을 분리한 뒤 반복문이 끝날 때마다 통째로 갱신함.

추가로 합(s)이 오름차순으로 탐색되는 점을 활용해, target 이상이 되면 그보다 큰 값은 더 볼 필요가 없으므로 탐색을 즉시 멈추는 가지치기(break)를 더해 최적화함.

## 구현

```java
import java.util.*;

class Solution {
    public int minimizeTheDifference(int[][] mat, int target) {
        
        boolean[] dp = new boolean[5000]; 
        dp[0] = true; //처음엔 가능한 합 0으로 시작

        for(int i = 0; i < mat.length; i++){
            //이번 층(i)의 결과를 담을 새로운 1차원 배열 준비
            boolean[] nextDp = new boolean[5000];
            
            for(int s = 0; s < 5000; s++){
                if(dp[s]){ //직전 층(dp)에서 가능했던 합

                    for(int k = 0; k < mat[0].length; k++){
                        //새로운 배열(nextDp)에 기록
                        nextDp[s + mat[i][k]] = true; 
                    }
                    
                    //가지치기
                    //s는 오름차순으로 탐색하다보니 처음 target 넘는 것이 그 뒤에 나오는 것들 보다 차이가 제일 작음
                    if (s >= target) break; 
                }
            }

            //층 계산이 끝나면, 다음 층 기록을 현재 기록으로 덮어치기(직전 층의 정보만 필요함)
            dp = nextDp;
        }

        //가능했던 합 돌며 최소 차이 구하기
        int answer = 1_000_000_000;
        for(int s = 0; s < 5000; s++) {
            if(dp[s]) { 
                answer = Math.min(answer, Math.abs(target - s));
            }
        }

        return answer;
    }
}
```
