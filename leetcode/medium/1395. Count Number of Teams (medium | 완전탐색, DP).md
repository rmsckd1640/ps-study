## 문제 요약

n명의 병사가 줄 서 있고, 각각 가치가 있음.

규칙을 따르며 3명씩 팀으로 묶을거임.

3명을 팀으로 묶었을 때 가치가 오름차순, 혹은 내림차순, 인덱스는 오름차순

몇 개의 팀을 짤 수 있음?

## 핵심 조건 및 제약 사항

병사 수 n → 3~1000

## 구현

```java
class Solution {
    public int numTeams(int[] rating) {
        int n = rating.length;
        int answer = 0;

        for (int i = 1; i < n - 1; i++) {

            // 왼쪽 자기보다 작은 개수와 큰 개수
            int ltSmallCnt = 0;
            int ltBigCnt = 0;
            for (int j = 0; j < i; j++) {
                if (rating[i] > rating[j]) ltSmallCnt++;
                else if (rating[i] < rating[j]) ltBigCnt++;
            }

            // 오른쪽 자기보다 작은 개수와 큰 개수
            int rtSmallCnt = 0;
            int rtBigCnt = 0;
            for (int j = i + 1; j < n; j++) {
                if (rating[i] > rating[j]) rtSmallCnt++;
                else if (rating[i] < rating[j]) rtBigCnt++;
            }

            // 오름차순
            answer += ltSmallCnt * rtBigCnt;

            // 내림차순
            answer += ltBigCnt * rtSmallCnt;
        }

        return answer;
    }
}
```

## 회고

조합기반 백트래킹으로 풀려했지만 시간초과 가능성이 높아서 다른 방법을 생각함.($O(1000C3)$)

반복문을 돌면서 중간값을 기준으로 왼쪽에 자기보다 작은거 오른쪽에는 자기보다 큰거의 개수를 구해 오름차순 개수를 구하고 반대로해서 내림차순 개수를 구하면 됨.

하지만 이건 3개일 때만 먹히는 로직이고 만약 더 커진다면 DP로 풀어야 함.

## 추가 구현(DP)

DP는 상태 정의가 가장 중요하다고 생각한다.

상태를 정의할 때는 "이 상태가 이전 상태로부터 어떻게 전이될 수 있는가?"를 함께 생각해야 한다.

이번 문제에서는 i번째 숫자가 수열의 마지막 원소일 때의 정보를 저장하면 전이가 자연스럽게 이루어질 것이라고 생각했다.

따라서 `dp[i][len] = i번째 숫자를 마지막 원소로 하는 길이 len 증가(감소) 부분수열의 개수`로 정의하였다.

이렇게 정의하면 이전 위치 j의 숫자와 현재 숫자를 비교하여 증가 또는 감소 조건을 만족할 때, 길이 len-1 수열에 현재 숫자를 붙여 길이 len 수열로 전이할 수 있다.

```java
class Solution {
    public int numTeams(int[] rating) {
        int n = rating.length;

        // 오름차순, 내림차순 전이 따로
        int[][] updp = new int[n][4];
        int[][] downdp = new int[n][4];

        // 초기화
        // 모든 원소가 자기 자신만으로 길이 1
        for (int i = 0; i < n; i++) {
            updp[i][1] = 1;
            downdp[i][1] = 1;
        }

        for (int i = 1; i < n; i++) {
            for (int j = 0; j < i; j++) {

                // 오름차순
                if (rating[i] > rating[j]) {
                    updp[i][2] += updp[j][1];
                    updp[i][3] += updp[j][2];
                }

                // 내림차순
                if (rating[i] < rating[j]) {
                    downdp[i][2] += downdp[j][1];
                    downdp[i][3] += downdp[j][2];
                }
            }
        }

        int answer = 0;

        for (int i = 0; i < n; i++) {
            answer += updp[i][3];
            answer += downdp[i][3];
        }

        return answer;
    }
}
```
