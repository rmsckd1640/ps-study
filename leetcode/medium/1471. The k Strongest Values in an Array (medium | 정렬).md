## 문제 요약

값끼리 비교하는데, 값에서 배열의 중간값을 뺀거의 절대값이 더 크면 더 강하다고 함.

만약 같으면 그냥 값끼리 비교해서 절대값이 더 큰게 강함.

여기서 중간값이란 배열을 오름차순 정렬했을 때 `(n-1)/2`의 인덱스 값을 말함. (0-based)

가장 강한 값 k개를 찾아 반환하라. 결과 배열 내 순서는 상관x

## 핵심 조건 및 제약 사항

배열의 크기 1 ~ 100,000

배열의 값 -100,000 ~ 100,000

k개 → 1 ~ 배열의 크기

## 시행착오

원본 값은 그대로 가져가야 하기 때문에 중간값을 뺀거의 절대값을 또 따로 같이 가져가야 비교가 쉬움.

클래스를 만들어서 정렬 기준 만들면 될듯 (객체 스스로 정렬 기준을 가지게 만드는 방식 → Comparable)

## 구현

```java
import java.util.*;

class Number implements Comparable<Number> {
    int val;
    int cal;

    public Number(int val, int cal) {
        this.val = val;
        this.cal = cal;
    }

    @Override
    public int compareTo(Number n) {
        // 계산한 값이 같을 때 그냥 값 기준 내림차순
        if (this.cal == n.cal) {
            return n.val - this.val;
        }
        return n.cal - this.cal;
    }
}

class Solution {
    public int[] getStrongest(int[] arr, int k) {
        Arrays.sort(arr);
        int mid = arr[(arr.length - 1) / 2];

        Number[] res = new Number[arr.length];
        for (int i = 0; i < arr.length; i++) {
            int cal = Math.abs(arr[i] - mid);
            res[i] = new Number(arr[i], cal);
        }

        Arrays.sort(res);

        int[] answer = new int[k];
        for (int i = 0; i < k; i++) {
            answer[i] = res[i].val;
        }

        return answer;
    }
}
```

## 추가 구현

원본값과 계산값을 따로 가져가지않고, 클래스를 따로 만들지 않고, 람다로 할 수도 있음 (정렬 기준을 외부에서 별도로 정의해주는 방식 → Comparator)

```java
Arrays.sort(ar, (a, b) -> {
    if (Math.abs(a - m) == Math.abs(b - m)) {
        return b - a;
    }
    return Math.abs(b - m) - Math.abs(a - m);
});
```
