## 문제 요약

문자열 두개를 합치는데, 하나의 문자열 끝과 다른 하나의 문자열 앞이 같으면 문자 하나를 지우고 붙임.

주어진 문자열을 순서대로 붙일 건데, 앞에서 만들어온 문자열의 뒤에붙일지 앞에 붙일지 선택할 수 있음.

만들어지는 최종 문자열의 길이가 최소가 되도록 구하기

## 핵심 조건 및 제약 사항

배열의 총 크기는 최대 50으로 완전탐색은 시간초과 가능성 높음.

## 구현

```java
import java.util.*;

class Solution {
    public int minimizeConcatenatedLength(String[] words) {

        // i번째일때 시작문자와 끝문자의 상태일 때 문자열 길이를 담을 것임.
        // 영어 알파벳를 0~25로 생각
        int[][][] dp = new int[words.length][26][26];

        // 초기화
        // 아직 도달하지 못한 상태나, 최소 비교를 위해 INF로 채우기
        for (int i = 0; i < words.length; i++) {
            for (int j = 0; j < 26; j++) {
                Arrays.fill(dp[i][j], 1_000_000_000);
            }
        }

        int len = words[0].length();
        int s = words[0].charAt(0) - 'a';
        int e = words[0].charAt(len - 1) - 'a';
        dp[0][s][e] = len;

        for (int i = 1; i < words.length; i++) {

            len = words[i].length();
            s = words[i].charAt(0) - 'a';
            e = words[i].charAt(len - 1) - 'a';

            for (int ps = 0; ps < 26; ps++) {
                for (int pe = 0; pe < 26; pe++) {

                    if (dp[i - 1][ps][pe] == 1_000_000_000) continue;

                    int newlen = 0;

                    // 뒤에 붙이기 (전 단어의 끝, 현재 단어의 시작 비교)
                    if (pe == s)
                        newlen = len + dp[i - 1][ps][pe] - 1;
                    else
                        newlen = len + dp[i - 1][ps][pe];

                    // 전 단어의 시작, 현재 단어의 끝 자리에 넣기
                    dp[i][ps][e] = Math.min(dp[i][ps][e], newlen);

                    // 앞에 붙이기 (전 단어의 시작, 현재 단어의 끝)
                    if (ps == e)
                        newlen = len + dp[i - 1][ps][pe] - 1;
                    else
                        newlen = len + dp[i - 1][ps][pe];

                    // 현재 단어의 시작, 전 단어의 끝 자리에 넣기
                    dp[i][s][pe] = Math.min(dp[i][s][pe], newlen);
                }
            }
        }

        int answer = 1_000_000_000;

        for (int i = 0; i < 26; i++) {
            for (int j = 0; j < 26; j++) {
                answer = Math.min(answer, dp[words.length - 1][i][j]);
            }
        }

        return answer;
    }
}

// 상태가 완전히 같을 때에는 길이가 더 짧은걸로 갱신
```

## 회고

dp 문제는 상태 정의하는게 가장 어려운 것 같다.

이 문제 풀면서 느꼈던 것은 상태 정의를 어떻게 할지를 배열로 표현하는 것이다.

>"i번째 단어를 이어 붙였을 때 시작 단어와 끝 단어의 상태에서의 최소 길이"
→ [i][start][end] 자리에 최소 길이 넣기

처음에 INF로 초기화 하는 과정과 `Math.min()`으로 비교하여 갱신하는 부분이 생각나지 않았는데, 결국 전이 되면서 문자를 이어 붙이기 때문에 지금 어떤 상태가 전이가 됐는지 확인하는 용도(전이가 되지 않았으면 도달할 수 없음)도 있을 뿐더러 최소길이를 갱신해야 하기 때문인 용도도 있다.

비교하여 갱신하는 부분은 i번째에 같은 상태이지만 앞에서 붙이든 뒤로 붙이든 상태가 같을 수 있는데 더 짧은 경우를 넣기 위함이다.
