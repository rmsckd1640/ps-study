## 문제 요약

문자열 배열이 있는데 몇 개를 골라 붙였을 때 모든 글자가 다 다르고 제일 긴 길이 출력

## 핵심 조건 및 제약 사항

배열 길이 → 1 ~ 16

각 문자열의 길이 → 1 ~ 26 (알파벳 소문자)

## 시행착오

부분 집합 기반 백트래킹 → 범위가 널널해서 통과 → 하지만 다 골랐을 때마다 문자열로 바꾸고 문자열의 각 문자를 map에 저장해서 겹치는게 있는지 검사하고 최대 길이랑 비교해서 갱신하는 매우 비효율적이었다. (1942ms)

그래서 다 선택해서 중복검사하지 말고 선택할 때마다 중복검사하여 그 뒤로 더 이상 뻗기 않게 가지치기하기. (92ms)

시간이 대폭 줄 긴 했지만, 이 방법도 매번 문자열을 붙이고 확인하기 때문에 비효율적이다. → 체크 배열을 통해 사용했던 알파벳을 관리하며 인자로 넘기자. 그러면 매번 새로 만들지 않고 넘긴 체크 배열을 활용하여 확인만 하면 됨!

또한 list를 들고다니며 StringBuilder를 매번 만들 필요없다. 결국 길이만 구하는 것이기 때문에 길이를 관리해서 넘겨주면 됨!

## 구현

```java
import java.util.*;

class Solution {
    static int max;

    static void dfs(int L, List<String> arr, boolean[] ch, int len){
        if(L == arr.size()){
            max = Math.max(max, len);
            return;
        }

        else{
            boolean flag = false;
            boolean[] tempCh = new boolean[26];
            
            //지금 나온 문자열 체크
            for(char c : arr.get(L).toCharArray()){
                int idx = c - 'a';
                if (tempCh[idx]) { //이미 true인데 또 나왔다면 자체 문자열 안에서 중복!!
                    flag = true;
                    break; //여기서 return하면 비선택으로 못 뻗어나감!
                }
                tempCh[idx] = true;
            }

            //원래 문자열이랑 비교시 겹치는거 있는지 확인
            for(char c : arr.get(L).toCharArray()){
                if(ch[c-'a'] && tempCh[c-'a']) flag = true;
            } 

            //겹치는 게 없을 때 선택
            if(!flag){
                for(char c : arr.get(L).toCharArray()){
                    if(!ch[c-'a']) ch[c-'a'] = true;
                }

                //문자열 길이 합쳐서 넘기기
                dfs(L+1, arr, ch, len + arr.get(L).length());

                for(char c : arr.get(L).toCharArray()){
                    if(ch[c-'a']) ch[c-'a'] = false;
                }
            }

            //비선택
            dfs(L+1, arr, ch, len);
        }
    }

    public int maxLength(List<String> arr) {
        boolean[] ch = new boolean[26];

        max = 0;
        dfs(0, arr, ch, 0);

        return max;
    }
}
```

## 추가 구현 (비트마스킹 활용)

|= 이거랑 = 이거랑 헷갈렸는데 그냥 = 이거는 단일 스위치 킨거고 여러 스위치가 켜져있을 땐 |= 이렇게 해야 함.

조건문 안에서 연산자 우선순위 때문에 &연산자 먼저 하기 위해서 괄호로 묶기!

```java
import java.util.*;

class Solution {
    static int max;

    static void dfs(int L, List<String> arr, int bitmask, int len){
        if(L == arr.size()){
            max = Math.max(max, len);
            return;
        }

        else{

            boolean flag = false;

            //현재 문자열
            String str = arr.get(L);
            int curBitmask = 0;

            for(char c : str.toCharArray()){
                int bit = 1 << (c-'a');
                if((curBitmask & bit) != 0){ //자체 중복 검사
                    flag = true;
                    break;
                }

                curBitmask |= 1 << (c-'a');
            }

            //넘어온 문자열과 비교
            if((bitmask & curBitmask) != 0) flag = true; //앤드 연산을 했을 때 같다면 0이 아님 -> 0이 아니면 중복

            //선택하여 합치기
            if(!flag) dfs(L+1, arr, bitmask | curBitmask, len + str.length());

            //비선택
            dfs(L+1, arr, bitmask, len);
        }
    }

    public int maxLength(List<String> arr) {
        boolean[] ch = new boolean[26];

        int bitmask = 0;

        max = 0;
        dfs(0, arr, bitmask, 0);

        return max;
    }
}
```

## 추가 구현 (DP)

`Integer.bitCount(x)` = **이진수에서 1의 개수 세는 함수**

리스트의 크기가 변할 때는 for-each 절대 금지

```java
import java.util.*;

class Solution {
    public int maxLength(List<String> arr) {
        int answer = 0;

        //문자열들을 비트마스킹하여 넣을건데 유효한것만(자체에서 겹치는거 제외)
        List<Integer> valid = new ArrayList<>();

        for(String str : arr){
            int bitmask = 0;
            boolean flag = false;

            for(char c : str.toCharArray()){
                int bit = 1 << (c - 'a');

                if((bit & bitmask) != 0){
                    flag = true;
                    break;
                }

                bitmask |= bit;
            }

            if(!flag) valid.add(bitmask);
        }
    
        //부분 집합 만들기
        List<Integer> dp = new ArrayList<>();
        dp.add(0); //초기값 설정!

        for(int curMask : valid){
            int size = dp.size();
            for(int i=0; i<size; i++){
                int subMask = dp.get(i);
                if((curMask & subMask) == 0){
                    int temp = curMask | subMask;
                    dp.add(temp);
                    answer = Math.max(answer, Integer.bitCount(temp));
                }
            }
        }

        return answer;
    }
}
```
