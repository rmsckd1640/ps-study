## 문제 요약

스도쿠 배열이 주어지는데 지금 주어진 상태가 스도쿠 규칙을 잘 따르는지 안따르는지 반환

## 핵심 조건 및 제약 사항

스도쿠 배열 크기 → 9x9

## 구현

```java
import java.util.*;

class Solution {

    static int[] dx = {-1, 0, 1, 1, 1, 0, -1, -1};
    static int[] dy = {-1, -1, -1, 0, 1, 1, 1, 0};

    public boolean isValidSudoku(char[][] board) {

        boolean[] row;
        boolean[] col;
        boolean[] box;

        // 중앙
        for (int i = 1; i <= 7; i += 3) {
            for (int j = 1; j <= 7; j += 3) {
                box = new boolean[10];

                if (board[i][j] != '.') {
                    int cur = board[i][j] - '0';
                    box[cur] = true;
                }

                for (int k = 0; k < 8; k++) {
                    int nx = i + dx[k];
                    int ny = j + dy[k];

                    if (board[nx][ny] != '.') {
                        int temp = board[nx][ny] - '0';

                        if (box[temp]) {
                            return false;
                        }

                        box[temp] = true;
                    }
                }
            }
        }

        // 행
        for (int i = 0; i < 9; i++) {
            row = new boolean[10];

            for (int j = 0; j < 9; j++) {
                if (board[i][j] == '.') {
                    continue;
                }

                int cur = board[i][j] - '0';

                if (row[cur]) {
                    return false;
                }

                row[cur] = true;
            }
        }

        // 열
        for (int i = 0; i < 9; i++) {
            col = new boolean[10];

            for (int j = 0; j < 9; j++) {
                if (board[j][i] == '.') {
                    continue;
                }

                int cur = board[j][i] - '0';

                if (col[cur]) {
                    return false;
                }

                col[cur] = true;
            }
        }

        return true;
    }
}
```

## 회고

이번문제도 해결방안으로 백트래킹, BFS를 떠올리며 완전탐색을 어떻게 할지 생각을 하다보니 시간도 많이 잡아먹었고 머릿속이 복잡해졌다.

다시 생각을 비우고 단순하게 "해당 칸의 행, 열의 중복을 검사하면 되겠구나 → 근데 시간 복잡도는 괜찮을까? → 3x3의 칸은 어떻게 할까? → 각 칸의 중심을 이용하여 8방향을 검사하면 되겠다" 이런식으로 생각을 펼쳐나갔다.
