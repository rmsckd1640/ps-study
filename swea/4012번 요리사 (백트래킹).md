## 문제 요약

N개의 식재료가 있고 각각 절반으로 나눠 2개의 요리를 할거임.(N은 짝수)

비슷한 맛의 음식을 만들기 위해 맛의 차이가 최소가 되도록 해야함.

맛은 구성하는 식재료들의 조합에 따라 다름.

테이블로 재료 궁합 시너지가 주어짐.

두 음식 간의 맛의 차이가 최소가 되는 최솟값 출력.

## 핵심 조건 및 제약 사항

식재료 수 N → 4 ~ 16

i == j 일 경우 정의되지 않음 (0으로 주어짐)

## 시행착오

N개중 절반을 선택 → 조합 기반 탐색

절반을 선택 했을 때 시너지의 합과 나머지 절반의 시너지의 합 차이를 계산한 후 최소 차이 갱신.

## 구현

```java
import java.util.*;

public class Solution {
    static int n;
    static int[][] arr;
    static int sumA, sumB;
    static int answer;
    static int[] ch;

    public static void DFS(int L, int start) {
        if (L == n / 2) {
            sumA = 0;
            sumB = 0;

		for (int i = 0; i < n; i++) {
			for (int j = i + 1; j < n; j++) {
				if (ch[i] == 1 && ch[j] == 1) {
					sumA += arr[i][j] + arr[j][i];
				}
				else if (ch[i] == 0 && ch[j] == 0) {
					sumB += arr[i][j] + arr[j][i];
				}
			}
		}

            answer = Math.min(answer, Math.abs(sumA - sumB));
            return;
        }

        for (int i = start; i < n; i++) {
            ch[i] = 1;
            DFS(L + 1, i + 1);
            ch[i] = 0;
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int T = sc.nextInt();

        for (int tc = 1; tc <= T; tc++) {
            n = sc.nextInt();

            arr = new int[n][n];
            ch = new int[n];
            answer = Integer.MAX_VALUE;

            for (int i = 0; i < n; i++) {
                for (int j = 0; j < n; j++) {
                    arr[i][j] = sc.nextInt();
                }
            }

            DFS(0, 0);

            System.out.println("#" + tc + " " + answer);
        }
    }
}
```

## 추가 구현

위와 같이 풀었을 때 시간복잡도는 n개중 n/2개 선택 및 선택했을 때 마다 합 계산이 최대 $O(n^2)$, 총 $O(C(n, n/2)·n^2)$이다.

문제 조건의 n의 범위 안에서는 충분히 해결될 수 있지만 n이 커진다면 시간 초과가 날 것이다.

그렇다면 어떻게 시간복잡도를 줄일 수 있을까?

현재 코드를 해석해보자. 매번 조합을 생성할 때마다 시너지의 합을 계산하고 비교한다.

매 조합마다 전체 시너지를 다시 계산하지 않고, 새로 추가되는 재료 기준으로만 누적 계산하여
$O(C(n, n/2) · n)$으로 최적화할 수 있다.

```java
import java.util.*;

public class Solution {
    static int n;
    static int[][] arr;
    static int answer;
    static int[] ch;

    public static void DFS(int idx, int cntA, int cntB, int sumA, int sumB) {
        // 각 음식이 절반보다 많이 선택할 경우 가지치기
        if (cntA > n / 2 || cntB > n / 2) return;

        // 두 음식이 재료를 다 선택한 경우
        // (누적해와서 따로 시너지합 계산 필요없음)
        if (idx == n) {
            answer = Math.min(answer, Math.abs(sumA - sumB));
            return;
        }

        // A 음식에 idx번째 재료 넣었을 때
        ch[idx] = 1; // A음식에 배정
        int addA = 0;

        for (int i = 0; i < idx; i++) {
            // DFS에서 배정 완료된 재료 확인
            if (ch[i] == 1) {
                addA += arr[idx][i] + arr[i][idx];
            }
        }

        // 누적해서 넘기기
        DFS(idx + 1, cntA + 1, cntB, sumA + addA, sumB);

        // B 음식에 idx번째 재료 넣었을 때
        ch[idx] = 0;
        int addB = 0;

        for (int i = 0; i < idx; i++) {
            if (ch[i] == 0) {
                addB += arr[idx][i] + arr[i][idx];
            }
        }

        DFS(idx + 1, cntA, cntB + 1, sumA, sumB + addB);
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int T = sc.nextInt();

        for (int tc = 1; tc <= T; tc++) {
            n = sc.nextInt();

            arr = new int[n][n];
            ch = new int[n];
            answer = Integer.MAX_VALUE;

            for (int i = 0; i < n; i++) {
                for (int j = 0; j < n; j++) {
                    arr[i][j] = sc.nextInt();
                }
            }

            DFS(0, 0, 0, 0, 0);

            System.out.println("#" + tc + " " + answer);
        }
    }
}
```

굳이 인자로 안넘기고 전역 변수로 해도 되지만 되돌려줘야 하는 단점이 있다.
