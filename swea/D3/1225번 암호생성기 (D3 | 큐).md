## 문제 요약

8개의 숫자를 입력받고 첫 번째 수 부터 1 감소한 뒤 맨뒤로 보내고, 그 다음 2 감소한 뒤 맨 뒤로 보내고 ... 5 감소까지 반복 → 한 사이클

이 사이클을 반복해서 0보다 작아지는 경우 맨뒤로 보내고 끝냄 → 이 때의 8자리가 암호.

## 핵심 조건 및 제약 사항

각 수는 integer 범위를 넘지 않음.

정해지는 암호는 모두 한자리 수로 구성됨.

0보다 작아지는 경우 0으로 저장.

## 시행착오

앞에서 빼서 뒤로 넣기 위한 큐 사용.

큐에서 꺼내서 감소 시키고 뒤로 보내는데 0보다 작아지면 0으로 뒤로 보내고 종료.

감소를 위한 변수 i 사용. 한 사이클마다 1로 초기화.

## 구현

```java
import java.io.*;
import java.util.*;

class Solution {
    public static void main(String[] args) throws Exception {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        for (int tc = 1; tc <= 10; tc++) {
            br.readLine(); //테스트 케이스 번호 버리기 → tc로 출력할거임

            StringTokenizer st = new StringTokenizer(br.readLine());
            Deque<Integer> q = new ArrayDeque<>();

            for (int i = 0; i < 8; i++) {
                q.offer(Integer.parseInt(st.nextToken()));
            }

            int i = 1;
            while (true) {
                int temp = q.poll();
                temp -= i;
                if (temp < 0) temp = 0;
                q.offer(temp);

                if (temp == 0) break;

                i++;
                if (i > 5) i = 1;
            }

            StringBuilder sb = new StringBuilder();
            sb.append("#").append(tc).append(" ");

            for (int j = 0; j < 8; j++) {
                sb.append(q.poll()).append(" ");
            }

            System.out.println(sb.toString().trim());
        }
    }
}
```
