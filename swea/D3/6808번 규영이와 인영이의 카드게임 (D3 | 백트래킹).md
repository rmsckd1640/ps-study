## 문제 요약

1~18까지 무작위로 9장씩 나눠 가짐.

9라운드에 걸쳐서 각자 카드를 내는데 높은 수를 낸 사람이 두 카드에 적힌 수의 합만큼 점수를 얻음.

9라운드가 끝났을 때 총점이 높은사람이 승리, 같으면 무승부

규영이가 내는 카드의 순서를 고정했을 때 인영이가 어떻게 카드를 내는지에 따라 규영이의 이기는 경우와 지는 경우가 총 몇가지인지 구하라.

## 핵심 조건 및 제약 사항

각 정수는 1~18, 같은 정수는 없다.

규영이는 정수가 주어지는 순서대로 카드를 낸다.

## 시행착오

규영이가 내는 9장의 카드에 맞게 인영이의 9장을 모두 비교하는 순열로 풀자.

9라운드 까지 같을 때 승패를 기록하고 다시 돌아가서 다른 경우를 확인하는 백트래킹 전략을 사용.

인영이의 배열을 따로 구해야햐나? → 탐색 안에서 1~18까지 반복문을 돌리며  규영이가 갖고 있지 않은 카드일때만 비교하기 → 무한 루프 발생 → 현재 규영이의 카드와 비교했을 때 다르더라도 나중에 같을 수 있기 때문에 규영이의 카드를 입력받을 때도 방문 체크 해야한다.

근데 이렇게 탐색 안에서 18번의 반복문 돌리는 것은 비효율적이다. 규영이 카드를 입력받을 때 방문 체크도 해놨으니 인영이 배열을 따로 구할 때 금방 구하고 탐색 안에서 반복문을 9번만 돌리는게 더 효율적이다.

## 구현

```java
import java.util.*;
import java.io.*;

public class Solution{
	static int[] arrA; //규영이 카드
	static int[] arrB; //인영이 카드
	static int[] ch; //방문체크
	static int a = 0; //규영이 점수
	static int b = 0; //인영이 점수
	static int awin = 0; //규영이가 이기는 경우의 수
	static int alose = 0; //규영이가 지는 경우의 수
	
	public static void DFS(int L) {
		if(L == 9) {
			if(a > b) awin++;
			else if(a < b) alose++;
		}
		else {
			for(int i=0; i<9; i++) {
				if(ch[arrB[i]] == 0) {
					if(arrA[L] > arrB[i]) a += arrA[L] + arrB[i];
					else b += arrA[L] + arrB[i];
					ch[arrB[i]] = 1;
					DFS(L+1);
					ch[arrB[i]] = 0;
					if(arrA[L] > arrB[i]) a -= arrA[L] + arrB[i];
					else b -= arrA[L] + arrB[i];
				}
			}
		}
	}
	
	public static void main(String[] args) throws IOException{
		Scanner sc = new Scanner(System.in);
		int T = sc.nextInt();
		
		for(int test_case = 1; test_case <= T; test_case++) {
			int size = 9;
			arrA = new int[9];
			ch = new int[19];
			a=0;
			b=0;
			awin=0;
			alose=0; //테스트 케이스마다 초기화
			
			for(int i=0; i<9; i++) {
				arrA[i] = sc.nextInt();
				ch[arrA[i]] = 1;
			}
			
			arrB = new int[9];
			int idx = 0;
			for(int i=1; i<=18; i++) {
				if(ch[i] == 0) {
					arrB[idx] = i;
					idx++;
				}
			}
			
			DFS(0);
			
			System.out.println("#" + test_case + " " + awin + " " + alose);
		}
	}
}
```

## 추가 구현

백트래킹할 때 가지치기도 생각하면 성능을 더 효율적으로 해결할 수 있다.

이 문제에서는 "1~18점 까지 합친 총 171점에서 한쪽이 그 절반 이상을 얻는 순간 더 이상 가볼 필요도 없어진다"라는 조건으로 가지치기 할 수 있다.

여기서 주의할 점은 예를들어 4라운드까지 해서 규영이가 이겼다면 그냥 +1 하는 것이 아닌 그 뒤의 5라운드의 모든 경우의 수 전부 규영이가 이겼기 때문에 5!을 더해줘야한다.

```java
import java.util.*;
import java.io.*;

public class Solution {
    static int[] arrA; //규영이 카드
    static int[] arrB; //인영이 카드
    static int[] ch; //방문체크
    static int a = 0; //규영이 점수
    static int b = 0; //인영이 점수
    static int awin = 0; //규영이가 이기는 경우의 수
    static int alose = 0; //규영이가 지는 경우의 수
    //0! ~ 9! 미리 계산하여 사용
    static int[] fact = {1, 1, 2, 6, 24, 120, 720, 5040, 40320, 362880};

    public static void DFS(int L) {
        //가지치기
        if (a > 85.5 || b > 85.5) {
            if (a > b) awin += fact[9 - L];
            else if (a < b) alose += fact[9 - L];
            return;
        }
        if (L == 9) {
            if (a > b) awin++;
            else if (a < b) alose++;
        } else {
            for (int i = 0; i < 9; i++) {
                if (ch[arrB[i]] == 0) {
                    if (arrA[L] > arrB[i]) a += arrA[L] + arrB[i];
                    else b += arrA[L] + arrB[i];
                    ch[arrB[i]] = 1;
                    DFS(L + 1);
                    ch[arrB[i]] = 0;
                    if (arrA[L] > arrB[i]) a -= arrA[L] + arrB[i];
                    else b -= arrA[L] + arrB[i];
                }
            }
        }
    }

    public static void main(String[] args) throws IOException {
        Scanner sc = new Scanner(System.in);
        int T = sc.nextInt();

        for (int test_case = 1; test_case <= T; test_case++) {
            arrA = new int[9];
            ch = new int[19];
            a = 0;
            b = 0;
            awin = 0;
            alose = 0; //테스트 케이스마다 초기화

            for (int i = 0; i < 9; i++) {
                arrA[i] = sc.nextInt();
                ch[arrA[i]] = 1;
            }

            arrB = new int[9];
            int idx = 0;
            for (int i = 1; i <= 18; i++) {
                if (ch[i] == 0) {
                    arrB[idx] = i;
                    idx++;
                }
            }

            DFS(0);

            System.out.println("#" + test_case + " " + awin + " " + alose);
        }
    }
}
```

## 추가 구현

방문 배열을 쓰지않고 비트마스킹을 사용하여 속도 향상과 공간 절약을 할 수 있다.

이 문제에서는 방문 배열을 4바이트씩 19칸의 공간을 사용하는데 비트마스킹을 사용하면 `int`변수 하나 즉, 4바이트로 해결할 수 있다. (방문 배열을 쓸 때 `boolean`(1바이트)을 써서 `int`를 썼을 때 보다 절약할 수 있었다.)

```java
import java.util.*;
import java.io.*;

public class Solution {
    static int[] arrA; // 규영이 카드
    static int[] arrB; // 인영이 카드

    static int a = 0; // 규영이 점수
    static int b = 0; // 인영이 점수
    static int awin = 0; // 규영이가 이기는 경우의 수
    static int alose = 0; // 규영이가 지는 경우의 수
    
    // 0! ~ 9! 미리 계산하여 사용
    static int[] fact = {1, 1, 2, 6, 24, 120, 720, 5040, 40320, 362880};

    public static void DFS(int L, int flag) {
        // 가지치기
        if (a > 85.5 || b > 85.5) {
            if (a > b) awin += fact[9 - L];
            else if (a < b) alose += fact[9 - L];
            return;
        }
        if (L == 9) {
            if (a > b) awin++;
            else if (a < b) alose++;
        } else {
            for (int i = 0; i < 9; i++) {
                if ((flag & (1 << arrB[i])) == 0) {
                    if (arrA[L] > arrB[i]) a += arrA[L] + arrB[i];
                    else b += arrA[L] + arrB[i];
                    
                    DFS(L + 1, flag | (1 << arrB[i]));
                    
                    if (arrA[L] > arrB[i]) a -= arrA[L] + arrB[i];
                    else b -= arrA[L] + arrB[i];
                }
            }
        }
    }

    public static void main(String[] args) throws IOException {
        Scanner sc = new Scanner(System.in);
        int T = sc.nextInt();

        for (int test_case = 1; test_case <= T; test_case++) {
            arrA = new int[9];
            int flag = 0; // 비트마스킹 사용
            a = 0;
            b = 0;
            awin = 0;
            alose = 0; // 테스트 케이스마다 초기화

            for (int i = 0; i < 9; i++) {
                arrA[i] = sc.nextInt();
                flag |= (1 << arrA[i]);
            }

            arrB = new int[9];
            int idx = 0;
            for (int i = 1; i <= 18; i++) {
                if ((flag & (1 << i)) == 0) {
                    arrB[idx] = i;
                    idx++;
                }
            }

            DFS(0, flag);

            System.out.println("#" + test_case + " " + awin + " " + alose);
        }
    }
}
```
