## 문제 요약

회사에서 출발해서 N명의 고객을 모두 방문하고 집으로 돌아오는 최단 경로 찾기.

## 핵심 조건 및 제약 사항

두 위치 (x1, y1)와 (x2, y2) 사이의 거리는 |x1-x2| + |y1-y2|으로 계산된다.

고객의 수 N은 2≤N≤10 이다.

## 시행착오

고객을 어떤 순으로 방문해야 최단 경로가 나올지 백트래킹을 이용한 완전탐색하자(순열). → 가지치기를 하지 않는다면 10!이여서 아슬아슬하지만 문제에서 효율적으로 찾는 것이 목적이 아니라 했음.

좌표 클래스를 만들어 사용.

DFS 함수에서 현재 위치를 다음 시작 위치로 전달하여 다음 이동 거리 계산에 활용.

## 구현

```java
import java.util.*;
import java.io.*;

class Point {
    int x;
    int y;

    public Point(int x, int y) {
        this.x = x;
        this.y = y;
    }
}

public class Solution {
    static Point company;
    static Point home;
    static Point[] arr;
    static int n;
    static int min;
    static int sum;
    static int[] ch;

    public static void DFS(int L, Point p) {
        if (L == n) {
            sum += Math.abs(p.x - home.x) + Math.abs(p.y - home.y);
            min = Math.min(min, sum);
            sum -= Math.abs(p.x - home.x) + Math.abs(p.y - home.y);
        } else {
            for (int i = 0; i < n; i++) {
                if (ch[i] == 0) {
                    ch[i] = 1;
                    sum += Math.abs(p.x - arr[i].x) + Math.abs(p.y - arr[i].y);
                    DFS(L + 1, arr[i]);
                    ch[i] = 0;
                    sum -= Math.abs(p.x - arr[i].x) + Math.abs(p.y - arr[i].y);
                }
            }
        }
    }

    public static void main(String[] args) throws IOException {
        Scanner sc = new Scanner(System.in);
        int T = sc.nextInt();

        for (int test_case = 1; test_case <= T; test_case++) {
            n = sc.nextInt();
            company = new Point(sc.nextInt(), sc.nextInt());
            home = new Point(sc.nextInt(), sc.nextInt());
            arr = new Point[n];

            for (int i = 0; i < n; i++) {
                arr[i] = new Point(sc.nextInt(), sc.nextInt());
            }

            ch = new int[n];
            min = Integer.MAX_VALUE;
            sum = 0;

            DFS(0, company);
            System.out.println("#" + test_case + " " + min);
        }
    }
}
```

## 추가 구현

만약 가지치기를 해야한다면 어떻게 해야할까?
→ 새로운 경로를 계산하다가 현재 저장되어있는 가장 짧은 경로보다 같거나 커진다면 이쪽 경로는 더 이상 볼 필요가 없다!

```java
import java.util.*;
import java.io.*;

class Point {
    int x;
    int y;

    public Point(int x, int y) {
        this.x = x;
        this.y = y;
    }
}

public class Solution {
    static Point company;
    static Point home;
    static Point[] arr;
    static int n;
    static int min;
    static int sum;
    static int[] ch;

    public static void DFS(int L, Point p) {

        //가지치기
        if (sum >= min) return;

        if (L == n) {
            sum += Math.abs(p.x - home.x) + Math.abs(p.y - home.y);
            min = Math.min(min, sum);
            sum -= Math.abs(p.x - home.x) + Math.abs(p.y - home.y);
        } else {
            for (int i = 0; i < n; i++) {
                if (ch[i] == 0) {
                    ch[i] = 1;
                    sum += Math.abs(p.x - arr[i].x) + Math.abs(p.y - arr[i].y);
                    DFS(L + 1, arr[i]);
                    ch[i] = 0;
                    sum -= Math.abs(p.x - arr[i].x) + Math.abs(p.y - arr[i].y);
                }
            }
        }
    }

    public static void main(String[] args) throws IOException {
        Scanner sc = new Scanner(System.in);
        int T = sc.nextInt();

        for (int test_case = 1; test_case <= T; test_case++) {
            n = sc.nextInt();
            company = new Point(sc.nextInt(), sc.nextInt());
            home = new Point(sc.nextInt(), sc.nextInt());
            arr = new Point[n];

            for (int i = 0; i < n; i++) {
                arr[i] = new Point(sc.nextInt(), sc.nextInt());
            }

            ch = new int[n];
            min = Integer.MAX_VALUE;
            sum = 0;

            DFS(0, company);
            System.out.println("#" + test_case + " " + min);
        }
    }
}
```

실행시간이 1597ms → 302ms로 대폭 감소했다.
