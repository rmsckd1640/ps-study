## 문제 요약

모든 섬들을 연결해야함.

연결할 때 환경 부담금 정책이 있음.

모든 섬들을 잇는 최소 환경 부담금을 소수 첫째 자리에서 반올림하여 정수 형태로 출력.

## 핵심 조건 및 제약 사항

$환경 부담금 = 환경 부담 세율 * (해저터널 길이)^2$

섬의 개수 N → 1~1000

각 섬의 좌표 (x,y) → 0~1,000,000

환경 부담 세율 E → 0~1

좌표 차이를 제곱하는 과정에서 값이 int범위를 넘기 때문에 long을 써야 함

## 시행착오

이 문제는 모든 섬 간 연결이 가능한 **완전 그래프($E \approx V^2$)**이기 때문에 간선 수가 매우 많다. 따라서 모든 간선을 생성하고 정렬해야 하는 크루스칼 알고리즘보다, 간선을 미리 만들지 않고 필요한 순간에만 계산하는 프림 알고리즘이 더 효율적이다.

## 구현(프림)

PQ에서 어떤 정점까지의 비용이 가장 적은 간선을 꺼낸다.

방문했는지 안했는지 확인하고 안했다면 방문 처리하고 비용 더하기.

현재 정점에서 갈 수 있는 다른 모든 정점 비용을 계산에 PQ에 넣기.

위를 반복하다 큐가 비거나, 정점의 수만큼 이어지면 종료.

시간복잡도: 모든 간선을 확인하고, 그때마다 힙연산을 하는데, 힙 크기는 결국 정점의 수에 비례한다. → $O(V^2logV)$

```java
import java.util.*;

// 간선 정보
class Edge implements Comparable<Edge>{
    int ver;
    long cost;

    public Edge(int ver, long cost) {
        this.ver = ver;
        this.cost = cost;
    }

    @Override
    public int compareTo(Edge edge) {
        return Long.compare(this.cost, edge.cost); // 오름차순
    }
}

public class Solution{
    public static void main(String[] args){
        Scanner sc = new Scanner(System.in);
        
        int T = sc.nextInt();
        
        for(int tc=1; tc<=T; tc++) {
	        int n = sc.nextInt();
	
	        int[] x = new int[n];
	        for(int i = 0; i < n; i++) {
	            x[i] = sc.nextInt();
	        }
	
	        int[] y = new int[n];
	        for(int i = 0; i < n; i++) {
	            y[i] = sc.nextInt();
	        }
	
	        double e = sc.nextDouble();
	
	        boolean[] ch = new boolean[n];
	        PriorityQueue<Edge> pq = new PriorityQueue<>();
	
	        pq.offer(new Edge(0, 0)); // 시작 정점
	
	        long answer = 0;
	        int cnt = 0;
	
	        while(!pq.isEmpty()) {
	            Edge cur = pq.poll();
	
	            if(ch[cur.ver]) continue;
	
	            ch[cur.ver] = true;
	            answer += cur.cost;
	            cnt++;
	
	            if(cnt == n) break;
	
	            for(int i = 0; i < n; i++) {
	                if(!ch[i]) {
	                    long dx = (long)x[cur.ver] - x[i];
	                    long dy = (long)y[cur.ver] - y[i];
	                    long cost = dx * dx + dy * dy;
	
	                    pq.offer(new Edge(i, cost));
	                }
	            }
	        }
	
	        System.out.println("#"+tc+" "+Math.round(answer * e));
        }
    }
}
```

## 추가 구현(크루스칼)

모든 간선의 비용을 계산하여 리스트에 넣고, 오름차순으로 정렬한다.

각 정점을 자기 자신을 대장으로 하는 독립된 팀으로 초기화

정렬된 간선을 하나씩 꺼내며, 두섬의 대장이 다른지 확인.

대장이 다르면 연결하고 비용 더하기.

모든 간선을 탐색하다가 간선이 V-1개가 되면 종료.

시간복잡도: 정렬이 지배적 → $O(V^2logV^2)$

```java
import java.util.*;

// 간선 정보
class Edge implements Comparable<Edge> {
    int x;
    int y;
    long cost;

    public Edge(int x, int y, long cost) {
        this.x = x;
        this.y = y;
        this.cost = cost;
    }

    @Override
    public int compareTo(Edge edge) {
        return Long.compare(this.cost, edge.cost); // 오름차순
    }
}

public class Solution {
    static int[] unf;

    public static void Union(int a, int b) {
        int fa = Find(a);
        int fb = Find(b);
        if (fa != fb) unf[fa] = fb;
    }

    public static int Find(int v) {
        if (unf[v] == v) return v;
        else return unf[v] = Find(unf[v]);
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int T = sc.nextInt();

        for (int tc = 1; tc <= T; tc++) {

            int n = sc.nextInt();

            unf = new int[n];
            for (int i = 0; i < n; i++) {
                unf[i] = i;
            } // 초기화 꼭 해주기!!!

            int[] x = new int[n];
            for (int i = 0; i < n; i++) {
                x[i] = sc.nextInt();
            }

            int[] y = new int[n];
            for (int i = 0; i < n; i++) {
                y[i] = sc.nextInt();
            }

            double e = sc.nextDouble();

            List<Edge> list = new ArrayList<>();

            for (int i = 0; i < n; i++) {
                for (int j = i + 1; j < n; j++) {
                    long dx = (long) x[i] - x[j];
                    long dy = (long) y[i] - y[j];
                    long cost = dx * dx + dy * dy;

                    list.add(new Edge(i, j, cost));
                }
            }

            Collections.sort(list);

            int cnt = 0;
            long totalCost = 0;

            for (Edge edge : list) {
                // 간선의 두 정점이 연결되어있는지 확인
                if (Find(edge.x) != Find(edge.y)) {
                    // 안되어 있다면 연결
                    Union(edge.x, edge.y);
                    // 비용 추가
                    totalCost += edge.cost;
                    // 간선 수 추가
                    cnt++;
                }

                // 간선의 개수가 (정점의 개수 - 1)개 이면 MST 완성
                if (cnt == n - 1) break;
            }

            System.out.println("#" + tc + " " + Math.round(totalCost * e));
        }
    }
}
```
