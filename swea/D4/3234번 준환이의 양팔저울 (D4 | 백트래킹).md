## 문제 요약

N개의 서로 다른 무게의 추와 양팔저울

무게 추를 올릴 때 오른쪽 위에 올라가 있는 무게의 총합이 왼쪽의 총합보다 커지면 안됨

양팔 저울에 모든 무게추를 올리는 방법은 몇 가지?

## 핵심 조건 및 제약 사항

무게 추 N → 1 ~ 9

각 무게 → 1 ~ 999

## 시행착오

왼쪽 무게가 항상 기준이 되므로 왼쪽을 채워나가는 방향으로 백트래킹 설계.

추를 놓는 순서도 결과에 영향을 준다 → 순열 기반 탐색.

오른쪽 무게가 왼쪽보다 커지는 경우 가지치기.

왼쪽과 오른쪽 무게를 인자로 전달하며 상태 관리.

## 구현

시간복잡도는 순열($N!$)과 각 단계에서의 좌/우 선택($2^N$)이 결합되어 이론상 $O(2^N·N!)$이다.

하지만 탐색 중 오른쪽 무게가 더 커지는 경우를 가지치기하여 실제 수행 시간은 훨씬 줄어든다.

```java
import java.util.*;

public class Solution {
    static int n;
    static int[] arr;
    static int answer;
    static boolean[] ch;

    public static void DFS(int L, int left, int right) {
        if (left < right) return;

        if (L == n) {
            answer++;
            return;
        }

        for (int i = 0; i < n; i++) {
            if (!ch[i]) {
                ch[i] = true;
                DFS(L + 1, left + arr[i], right);
                DFS(L + 1, left, right + arr[i]);
                ch[i] = false;
            }
        }
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int T = sc.nextInt();

        for (int tc = 1; tc <= T; tc++) {
            n = sc.nextInt();

            arr = new int[n];
            ch = new boolean[n];
            answer = 0;

            for (int i = 0; i < n; i++) {
                arr[i] = sc.nextInt();
            }

            DFS(0, 0, 0);

            System.out.println("#" + tc + " " + answer);
        }
    }
}
```

## 회고

왼쪽과 오른쪽 무게를 어떻게 관리할지 고민하면서 처음에는 전역으로 관리하려 했었다.

그러나 DFS에서 left, right를 인자로 넘기면서 각 호출이 독립적인 상태를 갖도록 하니 백트래킹이 훨씬 직관적으로 바뀌었다.

이후에는 상태를 어떻게 관리할지 고민이 된다면 인자로 넘겨주는 방식을 우선적으로 생각해야겠다!
