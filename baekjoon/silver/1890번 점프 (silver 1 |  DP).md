[백준 1890번 점프](https://www.acmicpc.net/problem/1890)

## 문제 요약

NxN 배열에서 첫번째 칸에서 끝 칸으로 규칙에 맞게 점프를 해서 가는 것. 규칙이란 각 칸에 적혀있는 수 만큼 오른쪽이나 아래로 점프.

처음 칸에서 끝 칸으로 규칙에 맞게 이동할 수 있는 경로의 개수 출력

## 핵심 조건 및 제약 사항

4 <= N <= 100

각 칸에 적혀있는 수의 범위 0~9

마지칵 칸은 항상 0

점프하는 도중에 방향 변경 x

경로의 개수는 2^63 - 1 보다 작거나 같다

## 시행착오

오른쪽, 아래쪽 이동 → 방향배열

DFS로 해당 칸에서 오른쪽으로 갔을 경우, 왼쪽으로 갔을 경우를 탐색하면 될 것 같음. → 인덱스 범위가 넘어가거나 끝 칸에 도착할 경우 return.

시간 초과 발생 → 여러 경로가 동일한 좌표로 반복해서 도달하게 되어 중복 계산이 발생하고 시간복잡도가 지수적으로 증가 → DP로 풀자.

경로의 개수가 2^63 - 1 보다 작거나 같다 → 경로의 개수를 담을 dp배열 `long`으로 선언하기.

누적해서 더해야 하는데 어떻게 누적하지? → 시작점의 경로의 개수를 1로 두기. 그래야 다음 경로가 1부터 쌓임

## 구현

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[][] arr = new int[n][n];
        for(int i=0; i<n; i++) {
        	for(int j=0; j<n; j++) {
        		arr[i][j] = sc.nextInt();
        	}
        }     
        
        long[][] dp = new long[n][n];
        dp[0][0] = 1;
        for(int i=0; i<n; i++) {
        	for(int j=0; j<n; j++) {
	        	if(dp[i][j] == 0) continue;
        		if(arr[i][j] != 0) {
	        		if(j + arr[i][j] < n) {
	        			dp[i][j + arr[i][j]] += dp[i][j];
	        		}
	        		if(i + arr[i][j] < n) {
	        			dp[i + arr[i][j]][j] += dp[i][j];
	        		}
        		}
        	}
        }
        
        System.out.println(dp[n-1][n-1]);
    }
}
```

## 회고

경로의 개수를 구하는 문제구나 하고 DFS를 생각했지만 시간초과가 나서 DP로 전환했다.
하지만 이 과정은 위험하다. 시간도 많이 소모되고, 테스트 케이스에 따라 시간초과가 발생하지 않으면 잘못된 풀이를 제출할 수도 있다.

그래서 더 좋은 기준은 다음과 같다.

DFS
→ 상태를 한 번만 방문하도록 제어 가능 (visited 등)
→ 모든 경로를 직접 탐색해야 함

DP
→ 상태를 여러 번 방문하게 됨 (중복 발생)
→ 한 번 계산한 결과를 재사용

이 문제의 경우, 같은 좌표에 여러 경로로 도달할 수 있으며, 이를 visited로 막아버리면 경로의 수가 누락되어 올바른 결과를 얻을 수 없다. 또한 해당 좌표에서의 결과는 항상 동일하므로, 중복 계산을 피하기 위해 DP를 사용하는 것이 적절하다.
**앞으로는 경로의 개수를 구하는 문제에서 동일한 상태로 여러 번 도달하는 구조가 보이면 DFS보다 DP를 먼저 고려하도록 하자.**

또한 **문제의 조건이나 상황을 고려하여 자료형을 선택해야겠다고 느꼈다.**
이 문제의 경우, 문제에서 경로의 개수 범위가 명시되어 있어 dp 배열을 long으로 선언하면 되었지만, 만약 이러한 조건이 없었다면 문제의 구조를 보고 판단해야 한다.
각 좌표에서 이동이 여러 갈래로 분기되고, 이 값들이 DP를 통해 계속 누적되는 구조이기 때문에 경로의 수가 지수적으로 증가할 수 있다.
따라서 이러한 경우에는 int 범위를 초과할 가능성을 고려하여 초기부터 long 타입을 사용하는 것이 적절하다.
