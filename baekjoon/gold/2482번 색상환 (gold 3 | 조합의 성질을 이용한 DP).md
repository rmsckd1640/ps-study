## 문제 요약

인접한 두 색을 동시에 사용하지 않음

N개의 색으로 구성되어 있는 색상환에서 어떤 인접한 두 색도 동시에 선택하지 않으면서 서로 다른 K개의 색을 선택하는 경우의 수는?

## 핵심 조건 및 제약 사항

색의 개수 N → 4 ~ 1000

선택 개수 K → 1 ~ N

경우의 수를 1_000_000_003으로 나눈 나머지를 출력

## 구현

```java
import java.util.*;

public class Main{
	public static void main(String[] args) {
		Scanner sc = new Scanner(System.in);
		int n = sc.nextInt();
		int k = sc.nextInt();
		
		//k가 n/2보다 크면 인접하지 않게 고르는 것이 불가능함
		if(k > n/2) {
			System.out.println(0);
			return;
		}
		
		int[][] dp = new int[n+1][k+1];
		
		//초기값 설정
		for(int i=1; i<=n; i++) {
			dp[i][1] = i; //i개 중 1개를 고르는 가짓수는 i가지
			dp[i][0] = 1; //아무것도 안 고르는 가짓수는 1가지
		}
		
		for (int i = 2; i <= n; i++) {
			for (int j = 2; j <= k; j++) {
				dp[i][j] = (dp[i - 2][j - 1] + dp[i - 1][j]) % 1_000_000_003;
			}
		}
		
		//1번을 선택 했을 때와 안했을 때 원형 구조로 최종 계산하기
		int answer = (dp[n-3][k-1] + dp[n-1][k]) % 1_000_000_003;
		
		System.out.println(answer);
	}
}
```

## 회고

이 문제는 원형 구조와 인접 선택 제한이 동시에 존재해 상태 정의에서 어려움을 겪었다. 처음에는 이를 하나의 DP로 처리하려 했지만, 특정 원소를 기준으로 선택/비선택으로 나누어 선형 문제로 변환할 수 있다는 점을 깨달으며 해결의 실마리를 찾았다.

또한 k개를 한 번에 구성하려 했던 접근이 아니라, ‘마지막 선택’을 기준으로 이전 상태를 이어 붙이는 방식으로 DP를 이해하게 되었다. 이 과정에서 k개를 만들기 위해서는 자연스럽게 k-1, k-2와 같은 더 작은 선택 상태들이 필요하다는 점을 깨달았다.

마지막으로 `dp[i][0] = 1`이라는 초기 조건이 단순한 설정이 아니라, ‘아무것도 선택하지 않는 경우’를 하나의 유효한 상태로 인정하여 첫 선택이 가능하도록 만드는 핵심 요소임을 이해하게 되었다.

결국 이 문제를 통해 복잡한 구조는 경우를 나누어 단순화하고, DP는 작은 상태부터 누적하여 정답을 만들어가는 방식으로 접근해야 한다는 점을 배웠다.
