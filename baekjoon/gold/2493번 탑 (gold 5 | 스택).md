## 문제 요약

서로 다른 N개의 높이의 탑이 있음.

각 탑에서 왼쪽으로 레이저 신호를 보내는데 높이가 자신보다 크거나 같은 처음 탑이 수신함.

각각의 탑에서 발사한 레이저 신호를 어느 탑에서 수신하는지 출력.

## 핵심 조건 및 제약 사항

탑의 수 n 범위 1 ~ 500,000

탑의 번호는 1부터 시작

## 시행 착오

왼쪽으로 쏘니깐 역순으로 반복문을 돌려야겠다.

자기보다 큰 수가 나올 때 까지 대기하는 스택을 써야겠다.

스택이 비어있으면 push.

비어있지 않고, 자신보다 큰게 온다면 pop하고 번호 매기고 push.

번호를 매기기 위해 인덱스를 넣기. → 탑의 번호는 1부터 시작하므로 +1 해서 넣어야 함.

(나머지 처리) 스택에 남아있는건 수신하는 탑이 존재하지 않으니 0으로 출력.

메모리 초과 발생 → `BufferedReader`로 입력받고, `StringBuilder`로 한번에 출력해서 해결.

`answer` 배열은 이미 0으로 처리되어 있기 때문에 이 문제에 경우 나머지 처리를 딱히 안해줘도 됨.

## 구현 (역방향)

```java
import java.util.*;
import java.io.*;

public class Main{
	public static void main(String[] args) throws IOException{
		BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
		int n = Integer.parseInt(br.readLine());
		int[] arr = new int[n];
		int[] answer = new int[n];
		
		StringTokenizer st = new StringTokenizer(br.readLine());
		
		for(int i=0; i<n; i++) {
			arr[i] = Integer.parseInt(st.nextToken());
		}
		
		Deque<Integer> stack = new ArrayDeque<>();
		
		for(int i=n-1; i>=0; i--) {
			while(!stack.isEmpty() && arr[stack.peek()-1] <= arr[i]) {
				int temp = stack.pop()-1;
				answer[temp] = i+1;
			}
			
			stack.push(i+1);
		}
		
		StringBuilder sb = new StringBuilder(2*n);
		for(int i=0; i<n; i++) {
			sb.append(answer[i]).append(" ");
		}
		System.out.print(sb.toString().trim());
	}
}
```

## 회고

스택에 인덱스를 담아서 사용할 때에, 꺼냈을 때 꼭 배열의 인덱스로 넣어서 사용하는거 까먹지 말기.

`StringBuilder`를 사용할 때 미리 용량을 지정하면 실행 속도 향상, 메모리 절약의 효과를 얻을 수 있다.

나는 역방향으로 해서 내가 쐈을 때 닿는 탑을 확인하는 로직을 작성했지만, 반대로 누군가가 쐈을 때 내가 받는 정방향으로 푸는 풀이도 있다고 한다.
→ 스택에 비어있지 않거나, 스택이 탑이 나보다 작다면 내가 쏜걸 받지 못하니 pop을 하고 아니라면 기록하고 push

역방향에서는 스택에 쏜애들이 담겨져 있기 때고, 정방향에서는 맞는 애들이 담겨져 있다.

### 추가 구현 (정방향)

```java
import java.util.*;
import java.io.*;

public class Main{
	public static void main(String[] args) throws IOException{
		BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
		int n = Integer.parseInt(br.readLine());
		int[] arr = new int[n];
		int[] answer = new int[n];
		
		StringTokenizer st = new StringTokenizer(br.readLine());
		
		for(int i=0; i<n; i++) {
			arr[i] = Integer.parseInt(st.nextToken());
		}
		
		Deque<Integer> stack = new ArrayDeque<>();
		
		for(int i=0; i<n; i++) {
			while(!stack.isEmpty() && arr[stack.peek()] < arr[i]) {
				stack.pop();
			}
			
			// arr[stack.peek()] >= arr[i] -> while문에서 이 반대의 조건을 처리 했으니 굳이 안해도 됨
			if(!stack.isEmpty()) {
				answer[i] = stack.peek()+1;
			}
			
			stack.push(i);
		}

		
		StringBuilder sb = new StringBuilder(2*n);
		for(int i=0; i<n; i++) {
			sb.append(answer[i]).append(" ");
		}
		System.out.print(sb.toString().trim());
	}
}
```
