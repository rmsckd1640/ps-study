## 문제 요약

n가지 종류의 동전이 있음. 가치 다 다름.

가치의 합이 k원이 되는 경우의 수는?

각각의 동전은 몇 개라도 사용 가능.

순서 고려 안함(중복 안됨)

## 핵심 조건 및 제약 사항

동전의 종류 n → 1 ~ 100
목표 합 k → 1 ~ 10000

각 동전의 가치 → 1 ~ 100,000

## 시행착오

동전을 여러 번 넣어도 되는 무한 냅색

`dp[0] = 1`은 아무것도 선택하지 않은 상태라는 하나의 경우의 수를 의미한다. 이는 각 동전이 자기 자신의 가치와 같은 금액을 처음 채울 때 '1가지'를 온전히 더해줄 수 있게 하는 기준점이 된다.

## 구현

각 동전마다 목표 금액만큼 반복문을 돌기 때문에 $O(n·k)$

```java
import java.util.*;

public class Main{
	public static void main(String[] args) {
		Scanner sc = new Scanner(System.in);
		int n = sc.nextInt();
		int k = sc.nextInt();
		int[] arr = new int[n];
		for(int i=0; i<n; i++) {
			arr[i] = sc.nextInt();
		}
		
		int[] dp = new int[k + 1];
		dp[0] = 1;

		for (int i=0; i<n; i++) {
		    for (int j = arr[i]; j <= k; j++) {
		        dp[j] += dp[j - arr[i]];
		    }
		}

		System.out.println(dp[k]);
	}
}
```
