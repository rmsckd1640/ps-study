[백준 1759번 암호 만들기](https://www.acmicpc.net/problem/1759)

## 문제 요약

암호는 모음 한개 이상, 자음 두개 이상으로 구성되어 있음.

암호는 오름차순.

가능성 있는 암호 모두 출력하기.

## 핵심 조건 및 제약 사항

C개의 문자들 중 L개 선택. (3 ≤ L ≤ C ≤ 15)

모음 한개, 자음 두개 꼭 포함 및 오름차순.

전부 소문자, 중복된 알파벳 없음.

## 시행착오

순서 상관없이 C개중에 L개를 선택하는 조합 문제이다. → 백트래킹을 이용한 완전탐색하자.

주어진 배열에서 뽑고 오름차순인지 확인하려고 했지만, 디버깅 해보니 검사를 하지 않는 경우가 발생 → 어떻게 해야 오름차순 암호를 확인할까? → 애초에 문자들이 오름차순으로 정렬되어 있다면, 뽑기만 한다면 무조건 오름차순이 된다!!!

## 구현

```java
import java.util.*;

public class Main{
	static int L;
	static int C;
	static char[] arr;
	static StringBuilder sb = new StringBuilder();
	public static void DFS(int D, int start, char[] temp) {
		if(D == L) {
			if(isCheck(temp)) {
				for(int i=0; i<L; i++) {
					sb.append(temp[i]);
				}
				sb.append("\n");
			}
		}
		else {
			for(int i=start; i<C; i++) {
				temp[D] = arr[i];
				DFS(D+1, i+1, temp);
			}
		}
	}
	
	public static void main(String[] args) {
		Scanner sc = new Scanner(System.in);
		L = sc.nextInt();
		C = sc.nextInt();
		arr = new char[C];
		for(int i=0; i<C; i++) {
			arr[i] = sc.next().charAt(0);
		}
		Arrays.sort(arr); //오름차순으로 정렬해놓기!
		char[] temp = new char[L];
		DFS(0, 0, temp);
		
		System.out.println(sb.toString().trim());
	}
	
	public static boolean isCheck(char[] arr) {
		int acnt = 0;
		int bcnt = 0;
		for(int i=0; i<arr.length; i++) {
			if(arr[i] == 'a' || arr[i] == 'e' || arr[i] == 'i' || arr[i] == 'o' || arr[i] == 'u' ) {
				acnt++;
			}
			else bcnt++;
		}
		
		if(acnt >= 1 && bcnt >= 2) return true;
		
		return false;
	}
}
```
