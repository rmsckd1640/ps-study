## 문제 요약

동굴의 각 칸마다 도둑루피가 있는데 이 칸을 지나면 해당 도둑루피의 크기만큼 소지금 잃음.

링크는 잃는 금액을 최소로 하여 동굴 건너편까지 이동해야 함.

한 번에 상하좌우 인접한 곳으로 1칸 이동 가능.

링크가 잃을 수밖에 없는 최소 금액은?

## 핵심 조건 및 제약 사항

동굴의 크기 NxN → 2~125 → 0입력되면 프로그램 종료

각 칸 루피 k → 0~9

## 시행착오

양의 가중치만 있는 최단 거리 → 다익스트라

## 구현

```java
import java.util.*;

class Point implements Comparable<Point>{
	int x;
	int y;
	int cost;
	
	public Point(int x, int y, int cost) {
		this.x = x;
		this.y = y;
		this.cost = cost;
	}
	
	@Override
	public int compareTo(Point p) {
		return this.cost - p.cost;
	}
}

public class Main{
	
	static int n;
	static int[][] graph;
	static int[][] dis;
	static int[] dx = {-1, 1, 0, 0};
	static int[] dy = {0, 0, -1, 1};
	static int answer;
	
	public static void Dijk(int x, int y, int cost) {
		PriorityQueue<Point> pq = new PriorityQueue<>();
		
		dis[0][0] = cost;
		pq.offer(new Point(x, y, cost));
		
		while(!pq.isEmpty()) {
			Point cur = pq.poll();
			
			if(dis[cur.x][cur.y] < cur.cost) continue;
			
			for(int i=0; i<4; i++) {
				int nx = cur.x + dx[i];
				int ny = cur.y + dy[i];
				
				if(nx >= 0 && nx < n && ny >= 0 && ny < n) {
					if(dis[nx][ny] > cur.cost + graph[nx][ny]) {
						dis[nx][ny] = cur.cost + graph[nx][ny];
//						pq.offer(new Point(nx, ny, graph[nx][ny]));
						//누적 비용을 담아야한다!!!
						pq.offer(new Point(nx, ny, dis[nx][ny]));
					}
				}
			}
			
		}
	}
	
	public static void main(String[] args) {
		Scanner sc = new Scanner(System.in);
		int pro = 1;
		while(true) {
			n = sc.nextInt();
			if(n == 0) return;
			answer = 0;
			dis = new int[n][n];
			for(int i=0; i<n; i++) {
				Arrays.fill(dis[i], 1_000_000_000);
			}
			graph = new int[n][n];
			for(int i=0; i<n; i++) {
				for(int j=0; j<n; j++) {
					graph[i][j] = sc.nextInt();
				}
			}
			
			Dijk(0, 0, graph[0][0]);
			
			System.out.println("Problem " + pro + ": "+ dis[n-1][n-1]);
			pro++;
		}
	}
}
```
