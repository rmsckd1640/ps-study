## 문제 요약

어떤 k개의 글자들을 가르쳐야 학생들이 읽을 수 있는 단어의 개수가 최대가 되는지.

모든 단어는 anta로 시작되고, tica로 끝난다.

단어는 N개 밖에 없다.

학생들이 읽을 수 있는 단어의 최댓값을 구하시오.

## 핵심 조건 및 제약 사항

단어의 개수 n → 1 ~ 50

k개의 글자 → 0 ~ 26

단어의 길이 8 ~ 15

단어 중복 없음.

## 시행착오

처음에는 그리디를 생각했다.

단어를 필요한 글자 수 기준으로 오름차순 정렬한 뒤, 짧은 단어부터 필요한 글자를 선택하려고 했다.

하지만 이렇게 하면 긴 단어들이 같은 글자를 공유하는 경우를 고려하지 못한다.  
즉, 짧은 단어 여러 개를 읽는 것보다 특정 글자 조합을 선택해 긴 단어 여러 개를 동시에 읽는 것이 더 유리한 반례가 존재한다.

따라서 단순 그리디로는 최적해를 보장할 수 없다.

문제에서 `a, n, t, i, c`는 반드시 포함되어야 하므로, 실제로는 남은 21개의 알파벳 중 `(K - 5)`개를 선택하는 문제가 된다.

즉, 가능한 알파벳 조합을 모두 탐색하는 조합(백트래킹) 문제로 접근했다.

글자를 다 골라도 DFS 종료 조건에 만족 못하는 경우 있음! → 후보 알파벳 수 < 선택 개수면 둘 중 작은 값으로 맞춰야 함!

## 구현

후보 알파벳 개수 m개 중 k개 뽑기. 뽑은 다음 단어 개수 만큼 검사하는데 각 단어를 돌면서 읽을 수 있는지 체크 해야함.

시간복잡도 → $O( C(m, k) × N × L )$

```java
import java.util.*;
import java.io.*;

public class Main{
	static boolean[] learn = new boolean[26];
	static int n;
	static int k;
	static List<String> word;
	static List<Character> alphabet;
	static int answer = 0;
	
	public static void DFS(int L, int start) {
		if(L == k) { //다 고르면 비교 후 갱신
			int cnt = 0;
			for(int i=0; i<word.size(); i++) {
				String cur = word.get(i); //살펴볼 단어
				
				boolean flag = false;
				for(int j=0; j<cur.length(); j++) {
					//살펴볼 글자 인덱스
					int idx = cur.charAt(j) - 'a';
					if(!learn[idx]) {
						flag = true;
						break;
					}
				}
				
				if(!flag) cnt++;
			}
			
			//다 살펴본 후 최대값 갱신
			answer = Math.max(answer, cnt);
		}
		else {
			for(int i=start; i<alphabet.size(); i++) {
				int cur = alphabet.get(i) - 'a';
				if(!learn[cur]) {
					learn[cur] = true;
					DFS(L+1, i+1); //선택했을 때만
					learn[cur] = false;
				}
			}
		}
	}
	
	public static void main(String[] args) throws IOException{
		BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
		
		StringTokenizer st = new StringTokenizer(br.readLine());
		n = Integer.parseInt(st.nextToken());
		k = Integer.parseInt(st.nextToken());
		
		//기본적으로 글자 5개 알아야 함
		if(k < 5) {
			System.out.println(0);
			return;
		}
		
		learn['a' - 'a'] = true;
		learn['n' - 'a'] = true;
		learn['t' - 'a'] = true;
		learn['i' - 'a'] = true;
		learn['c' - 'a'] = true;
		
		//글자 5개 빼고 고르면 됨
		k -= 5;
		
		
		word = new ArrayList<>();
		HashSet<Character> set = new HashSet<>();
		for(int i=0; i<n; i++) {
			String str = br.readLine();

			//새로운 문자 리스트에 추가
			word.add(str);
			
			//새로운 문자의 알파벳들 추가인데 아직 안배운것만
			//안배운것 중에서 뽑아서 배울거임
			for(char c : str.toCharArray()) {
				if(!learn[c-'a']) set.add(c);
			}
		}
		alphabet = new ArrayList<>(set);
		
		//알파벳을 다 골라도 k가 큰 경우 dfs 종료 조건 만족 못할 수 있음
		//둘 중 더 작은걸 k로 하기
		k = Math.min(k, alphabet.size());
		
		//조합
		DFS(0, 0);
		
		System.out.println(answer);
	}
}
```

## 추가 구현 (비트마스킹)

각 문자의 포함 여부를 하나씩 비교하지 않고, AND 연산으로 선택된 알파벳으로 구성되는지 한 번에 확인할 수 있다.

시간복잡도 → $O( C(m, k) × N)$

```java
import java.util.*;
import java.io.*;

public class Main{
	static int n;
	static int k;
	static int[] wordMask;
	static int answer = 0;
	
	public static void DFS(int L, int start, int mask) {
		if(L == k) { //다 고르면 비교 후 갱신
			int cnt = 0;
			for(int i=0; i<n; i++) {
				if((wordMask[i] & mask) == wordMask[i]) cnt++;
			}
			
			answer = Math.max(answer, cnt);
			
			return;
		}
		else {
			for(int i=start; i<26; i++) {
				//이미 선택된 것 제외
				if((mask & (1 << i)) == 0) DFS(L + 1, i + 1, mask | (1 << i));
			}
		}
	}
	
	public static void main(String[] args) throws IOException{
		BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
		
		StringTokenizer st = new StringTokenizer(br.readLine());
		n = Integer.parseInt(st.nextToken());
		k = Integer.parseInt(st.nextToken());
		
		//기본적으로 글자 5개 알아야 함
		if(k < 5) {
			System.out.println(0);
			return;
		}
		
		//글자 전부 다 배울 수 있다면 다 읽을 수 있음.
		if (k == 26) {
		    System.out.println(n);
		    return;
		}
		
		//배운 글자 비트마스크
		int mask = 0;
		
		mask |= 1 << ('a' - 'a');
		mask |= 1 << ('n' - 'a');
		mask |= 1 << ('t' - 'a');
		mask |= 1 << ('i' - 'a');
		mask |= 1 << ('c' - 'a');
		
		//글자 5개 빼고 고르면 됨
		k -= 5;
		
		
		wordMask = new int[n]; //n개의 각 단어의 비트마스크를 저장
		for(int i=0; i<n; i++) {
			String str = br.readLine();

			for(int j=0; j<str.length(); j++) {
				wordMask[i] |= 1 << (str.charAt(j) - 'a');
			}
		}

		//k개 선택하는 조합
		DFS(0, 0, mask);
		
		System.out.println(answer);
	}
}
```
