## 문제 요약

도서관에 학생들이 머물고 있는 가장 긴 시간, 학생이 하나도 없었던 가장 긴 시간 구하기

## 핵심 조건 및 제약 사항

학생 수 N → 1~10000

들어온 시각 S, 나간 시각 E → 1 ~ 2^31-1 

## 시행착오

들어온 시간 순 오름차순 정렬

다음 사람 입장이 먼저 왔던 학생의 나간 시간 포함 전인지 후인지 보고 계산

포함 전이면 시작은 계속 잡고있는 거고, 끝은 더 긴 애가 끝으로 하고 머문 시간 계산 → 전체 최대 머문 시간이 덮어씌어지지 않게 비교하여 갱신하기

포함이 아니면 시작도 바꾸고 끝도 바꾸고 다 갱신 해야하는데 학생 없는 시간 계산하고 갱신하기

## 구현

```java
import java.util.*;

class Student{
	int in;
	int out;
	
	public Student(int in, int out) {
		this.in = in;
		this.out = out;
	}
}

public class Main{
	public static void main(String[] args) {
		Scanner sc = new Scanner(System.in);
		
		int n = sc.nextInt();
		
		Student[] arr = new Student[n];
		
		for(int i=0; i<n; i++) {
			arr[i] = new Student(sc.nextInt(), sc.nextInt());
		}
		
		Arrays.sort(arr, (a, b) -> {
			return a.in - b.in;
		});
		
		int start = arr[0].in;
		int end = arr[0].out;
		int stay = end - start;
		int empty = 0;
		
		for(int i=1; i<n; i++) {
			
			//겹치는 경우
			if(arr[i].in <= end) {
				
				//현재 학생의 종료 시간이 더 길 때만 확장
				if(end < arr[i].out) {
					end = arr[i].out;
					
					//현재 병합 길이와 기존 최대 머문 시간 비교
					//(이전 최대값이 더 작은 구간에 의해 덮어써지는 것 방지)
					stay = Math.max(stay, end - start);
				}
			}
			
			//구간이 끊기는 경우
			else {
				
				//비어있는 최대 시간 갱신
				empty = Math.max(empty, arr[i].in - end);
				
				//새 구간 시작
				start = arr[i].in;
				end = arr[i].out;
				
				//새 구간 길이와 기존 최대 머문 시간 비교
				stay = Math.max(stay, end - start);
			}
		}
		
		System.out.print(stay + " " + empty);
	}
}
```

## 회고

처음에는 병합 중인 구간의 길이가 계속 증가한다고 생각하여 `stay = end - start` 방식으로 현재 구간 길이를 그대로 갱신했다.
하지만 테스트 과정에서 이전에 기록된 최대 머문 시간이 이후의 더 짧은 병합 구간에 의해 덮어써질 수 있다는 문제를 발견했다.  
즉, “현재 병합 구간의 길이”와 “전체 최대 머문 시간”은 다른 개념이라는 점을 놓치고 있었고, 이를 통해 구간 병합 문제에서는 현재 상태와 최적값을 분리해서 관리해야 한다는 것을 배웠다.
이후, `Math.max(stay, end - start)` 방식으로 수정하여 항상 최대값만 유지하도록 개선했다.
